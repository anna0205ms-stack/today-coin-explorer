# 통합 시장 대시보드 리뉴얼

기존 배포 주소 `https://anna0205ms-stack.github.io/today-coin-explorer/index.html`를 그대로 유지하면서 메인 화면만 UPBIT + BINANCE 통합 시장 대시보드로 교체한다.

- BTC 차트: TradingView `BINANCE:BTCUSDT`
- 시장 단계: M0~M5
- 시장 지표: BTC.D / TOTAL2 / OTHERS / 전체 알트 확산
- 거래소별 확산: UPBIT KRW / BINANCE SPOT USDT
- BTC 조정 시나리오: 1차 방어 / 2차 방어 / 구조 훼손
- 개별 코인 후보는 메인에서 제외
- UPBIT/BINANCE 스캐너와 데이터 수집은 계속 독립 유지
